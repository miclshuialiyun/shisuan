常见问题

已经扣款了，但高级版没有解锁？

请按以下顺序处理：

  1. 在 App「设置 → 恢复购买」点一次恢复（需联网，请使用与购买时相同的 Apple ID）。
  2. 重启 App，再试一次。
  3. 若仍未解锁，请发邮件给我们，附上「设置 → 查看购买记录」中的脱敏订单号、App 版本与 iOS 版本，我们会人工核对。

内购页如果同时出现「检测到解锁异常」等提示，也请把该提示截图一并发来，能大幅缩短排查时间。

换手机 / 重装后，方案都不见了？

时算没有账号与云端同步，数据只存在设备本地。因此换机前请务必：

  1. 在旧设备上打开「方案 → 右上角菜单 → 导出备份（JSON）」。
  2. 把生成的 JSON 文件保存到「文件」App、隔空投送或云盘。
  3. 在新设备上「方案 → 右上角菜单 → 导入备份」选择该文件。

若出现同名方案，可以选「覆盖同名方案」或「保留双方（重名加副本后缀）」。

为什么我算出来的「真实时薪」比我填的期望时薪还高？

因为「建议报价」里包含了期望利润率（默认 20%）与税费。 真实时薪 = 建议报价 ÷ 总投入工时（含沟通与返工）。利润率越高，真实时薪越可能超过你填的期望时薪。

真正反映「隐性成本吃掉多少」的是「朴素时薪」与「时薪缩水率」： 它们假设你只按「工时 × 时薪」报价，再把这个金额摊到全部投入工时上。

税费是按什么口径算的？

价外税：税费 = 不含税报价 × 税率，其中不含税报价 = 总成本 + 利润。 最终「建议报价」= 不含税报价 + 税费。这与常见的开票口径一致，也避免了「税上计税」的循环计算。 如果你的业务不需要计税，直接把「税费预估」关掉即可。

默认参数不适用于我的情况，能改吗？

可以。报价页右上角的滑杆图标进入「成本参数」，可以调整月自缴社保额、月可计费工时、 设备购入价、使用年限、年接单工时、沟通比例、返工比例与税率。 每项隐性成本也可以单独开关，关闭后即从测算中剔除。

PDF 报价单在哪里导出？

PDF 报价单属于高级版功能。在报价页或方案详情页点「导出 PDF 报价单」即可预览并分享。 如果按钮提示需要升级，说明当前是免费版。

数据会上传吗？

不会。时算不收集、不上传任何数据，也没有账号系统。所有计算与存储都在你的设备上完成， 也没有任何第三方统计或广告 SDK。详见隐私政策。

如何彻底删除我的数据？

「设置 → 清空全部本地数据」会删除所有方案与成本参数设置（不可恢复，操作前建议先导出备份）。 卸载 App 也会一并删除全部本地数据。
